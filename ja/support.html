よくある質問

データはどこに保存されますか？

すべてのデータ（お薬、注射、体重、副作用）は、お使いのスマートフォンの暗号化されたローカルデータベースにのみ保存されます。どのサーバーにもアップロードされません。Dozifyにはクラウドがありません。

スマートフォンを替えると、データは消えますか？

先にバックアップをとっておけば消えません。「設定 → バックアップと復元」で、パスワードで保護された暗号化バックアップファイルを作成し、新しいデバイスの同じ画面から復元してください。クラウド同期はやはりありません：バックアップファイル自体はあなたが保管するものです（ファイル、メール、AirDropなど）。

Premiumを解約するには？

サブスクリプションの管理や解約は、App Store（設定 → Apple ID → サブスクリプション）から行えます。解約すると以後の自動更新が停止し、支払い済みの期間が終わるまではPremiumを引き続き利用できます。

Premiumはほかのデバイスでも使えますか？

はい。新しいデバイスで、購読したときと同じApple IDでサインインした状態でPremium画面を開き、「購入を復元」をタップしてください。

Ozempic® / Wegovy®のペンタイプを追加するには？

「マイお薬 → 薬を追加 → OzempicまたはWegovyを選択 → 『プレフィルドペン』を選択 → 処方された用量を設定」の順に進みます。

Mounjaro®をペンとバイアルの両方から選べるのはなぜですか？

Mounjaroは、市場によってプレフィルドのKwikPenとして、また複数回使用のバイアルとして提供されています。Dozifyは両方の形を用意しているので、処方された製品に合ったものを選べます。

リマインダーが届きません。どうすればいいですか？

iPhoneの「設定 → 通知 → Dozify」を開き、通知をオンにしてください。また、「おやすみモード」や集中モードがDozifyの通知を消音していないかも確認してください。

すべてのデータを削除するには？

「設定 → データを削除」から、選んだカテゴリーだけを削除するか、すべてを削除するかを選びます。アプリをアンインストールしても、ローカルのデータはすべて完全に削除されます。

PDFレポートを作成するには？

「レポート → 新しいレポート → 要約・詳細・診察用のいずれかの形式を選択 → 期間を選択 → 作成」の順に進みます。PDFはメール、AirDrop、そのほかのアプリで共有できます。

アプリは医学的な助言をしますか？

いいえ。Dozifyは記録用のツールにすぎません。用量を推奨したり、医学的な結果を解釈したりすることはありません。臨床的な判断については、必ず医師や薬剤師に相談してください。
