자주 묻는 질문

내 데이터는 어디에 저장되나요?

모든 데이터(약물, 주사, 체중, 부작용)는 휴대폰 안의 암호화된 로컬 데이터베이스에만 저장돼요. 어떤 서버에도 업로드되지 않아요. Dozify에는 클라우드가 없어요.

휴대폰을 바꾸면 데이터가 사라지나요?

먼저 백업하면 사라지지 않아요. 설정 → 백업과 복원에서 암호로 보호되는 암호화된 백업 파일을 만든 다음, 새 기기의 같은 화면에서 복원하세요. 클라우드 동기화는 여전히 없어요: 백업 파일 자체는 내가 보관해요(파일 앱, 이메일, AirDrop 등).

Premium은 어떻게 해지하나요?

App Store(설정 → Apple ID → 구독)에서 구독을 관리하거나 해지하세요. 해지하면 이후 자동 갱신이 중단되며, 이미 결제한 기간이 끝날 때까지 Premium을 계속 쓸 수 있어요.

다른 기기에서도 Premium을 쓸 수 있나요?

네. 새 기기에서 구독할 때 쓴 Apple ID로 로그인한 상태에서 Premium 화면을 열고 "구매 복원"을 탭하세요.

Ozempic® / Wegovy® 펜 형태는 어떻게 추가하나요?

내 약 → 약 추가 → Ozempic 또는 Wegovy 선택 → "프리필드 펜" 선택 → 처방받은 용량 설정.

Mounjaro®는 왜 펜과 바이알 둘 다 고를 수 있나요?

Mounjaro는 일부 시장에서는 프리필드 KwikPen으로, 다른 시장에서는 다회용 바이알로 나와요. 처방받은 제품에 맞는 것을 고를 수 있도록 Dozify는 두 형태를 모두 제공해요.

알림이 오지 않아요. 어떻게 해야 하나요?

휴대폰 설정 → 알림 → Dozify에서 알림을 켜세요. "방해금지 모드"나 집중 모드가 Dozify 알림을 무음으로 하고 있지 않은지도 확인하세요.

내 데이터를 모두 삭제하려면 어떻게 하나요?

설정 → 데이터 삭제 → 선택한 항목 또는 전체 삭제를 고르세요. 앱을 삭제해도 모든 로컬 데이터가 영구적으로 삭제돼요.

PDF 리포트는 어떻게 만드나요?

리포트 → 새 리포트 → 요약, 상세, 진료용 형식 중 선택 → 기간 선택 → 생성. PDF는 이메일, AirDrop 또는 다른 앱으로 공유할 수 있어요.

앱이 의학적 조언을 하나요?

아니요. Dozify는 기록 도구일 뿐이에요. 용량을 권장하거나 검사 결과를 해석하지 않아요. 임상적인 결정은 항상 의사나 약사와 상담하세요.
