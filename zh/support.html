常见问题

我的数据存储在哪里？

你的所有数据（药物、注射、体重、副作用）都只存储在你的手机上，保存在加密的本地数据库中。不会上传到任何服务器。Dozify 没有云端。

换手机会丢失数据吗？

只要先备份就不会。前往“设置 → 备份与恢复”创建一个受密码保护的加密备份文件，然后在新设备上的同一界面恢复。仍然没有云同步：备份文件本身由你保管（文件 App、邮件、隔空投送等）。

如何取消 Premium？

通过 App Store（设置 → Apple ID → 订阅）管理或取消订阅。取消后将停止今后的续订：在已付费的周期结束前，你仍可继续使用 Premium。

我的 Premium 可以在另一台设备上使用吗？

可以。在新设备上，登录你订阅时使用的同一个 Apple ID，打开 Premium 界面并轻点“恢复购买”。

如何添加 Ozempic® / Wegovy® 注射笔剂型？

前往“我的药物 → 添加药物 → 选择 Ozempic 或 Wegovy → 选择‘预填充笔’→ 设置你的处方剂量”。

为什么 Mounjaro® 既可以选注射笔又可以选药瓶？

Mounjaro 在一些市场是预填充 KwikPen，在另一些市场是多剂量药瓶。Dozify 两种剂型都提供，让你可以选择与你的处方产品相符的那一种。

我的提醒不起作用：该怎么办？

打开手机的“设置 → 通知 → Dozify”，然后开启通知。另外请确认“勿扰模式”或某个专注模式没有将 Dozify 静音。

如何删除我的所有数据？

“设置 → 删除数据 → 选择删除所选类别或全部数据”。卸载应用也会永久删除所有本地数据。

如何生成 PDF 报告？

前往“报告 → 新建报告 → 选择摘要、详细或就诊格式 → 选择日期范围 → 生成”。PDF 可以通过邮件、隔空投送或任何其他应用分享。

这款应用提供医疗建议吗？

不提供。Dozify 只是一款记录工具。它不推荐剂量，也不解读医学检查结果。临床决定请始终咨询你的医生或药剂师。
