Perguntas frequentes

Onde são guardados os meus dados?

Todos os seus dados (medicamentos, injeções, peso, efeitos secundários) são guardados apenas no seu telemóvel, numa base de dados local encriptada. Nada é enviado para nenhum servidor. O Dozify não tem nuvem.

Se mudar de telemóvel, perco os meus dados?

Não, se fizer primeiro uma cópia de segurança. Vá a Ajustes → Backup e restauração para criar um ficheiro de cópia de segurança encriptado e protegido por palavra-passe, e depois restaure-o no novo dispositivo a partir do mesmo ecrã. Continua a não haver sincronização na nuvem: o ficheiro de cópia de segurança é seu para guardar (Ficheiros, email, AirDrop, etc.).

Como cancelo o Premium?

Gira ou cancele a sua subscrição na App Store (Definições → Apple ID → Subscrições). Cancelar impede as renovações futuras: mantém o Premium até ao fim do período que já pagou.

O meu Premium funciona noutro dispositivo?

Sim. No novo dispositivo, abra o ecrã Premium e toque em «Restaurar compras» com sessão iniciada no mesmo Apple ID com que fez a subscrição.

Como adiciono a forma de caneta do Ozempic® / Wegovy®?

Vá a Meus medicamentos → Adicionar medicamento → selecione Ozempic ou Wegovy → escolha «Caneta preenchida» → defina a dose prescrita.

Porque posso escolher o Mounjaro® como caneta e como frasco?

O Mounjaro existe como KwikPen preenchida nalguns mercados e como frasco multidose noutros. O Dozify oferece as duas formas para poder escolher a que corresponde ao produto que lhe foi receitado.

Os meus lembretes não funcionam: o que devo fazer?

Abra as Definições do telemóvel → Notificações → Dozify → ative as notificações. Verifique também se o «Não incomodar» ou um modo de concentração não está a silenciar o Dozify.

Como apago todos os meus dados?

Ajustes → Excluir dados → escolha apagar categorias selecionadas ou tudo. Desinstalar a app também apaga permanentemente todos os dados locais.

Como crio um relatório PDF?

Vá a Relatórios em PDF → Novo relatório → escolha Relatório resumido, Relatório detalhado ou Relatório para a consulta → selecione o período → Gerar relatório. O PDF pode ser partilhado por email, AirDrop ou qualquer outra app.

A app dá aconselhamento médico?

Não. O Dozify é apenas uma ferramenta de registo. Não recomenda doses nem interpreta resultados médicos. Consulte sempre o seu médico ou farmacêutico para decisões clínicas.
