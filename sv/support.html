Vanliga frågor

Var sparas mina data?

Alla dina data (läkemedel, injektioner, vikt, biverkningar) sparas bara i din telefon, i en krypterad lokal databas. Inget laddas upp till någon server. Dozify har inget moln.

Förlorar jag mina data om jag byter telefon?

Inte om du säkerhetskopierar först. Gå till Inställningar → Säkerhetskopiering och återställning för att skapa en lösenordsskyddad, krypterad säkerhetskopia och återställ den sedan på din nya enhet från samma skärm. Det finns fortfarande ingen molnsynkronisering: själva säkerhetskopian är din att behålla (Filer, e-post, AirDrop osv.).

Hur säger jag upp Premium?

Hantera eller avsluta ditt abonnemang i App Store (Inställningar → Apple-ID → Prenumerationer). När du avslutar stoppas kommande förnyelser: du behåller Premium till slutet av perioden du redan har betalat för.

Fungerar mitt Premium på en annan enhet?

Ja. Öppna Premium-skärmen på din nya enhet och tryck på ”Återställ köp” medan du är inloggad med samma Apple-ID som du tecknade abonnemanget med.

Hur lägger jag till pennformen av Ozempic® / Wegovy®?

Gå till Mina läkemedel → Lägg till läkemedel → välj Ozempic eller Wegovy → välj ”Förfylld penna” → ställ in din ordinerade dos.

Varför kan jag välja Mounjaro® både som penna och som flaska?

Mounjaro finns som förfylld KwikPen på vissa marknader och som flerdosflaska på andra. Dozify erbjuder båda formerna så att du kan välja den som motsvarar produkten du har fått utskriven.

Mina påminnelser fungerar inte: vad ska jag göra?

Öppna Inställningar → Notiser → Dozify i telefonen och slå på notiser. Kontrollera också att ”Stör ej” eller ett fokusläge inte tystar Dozify.

Hur raderar jag alla mina data?

Inställningar → Radera uppgifter → välj att radera utvalda kategorier eller allt. Att avinstallera appen raderar också alla lokala data permanent.

Hur skapar jag en PDF-rapport?

Gå till PDF-rapporter → Ny rapport → välj sammanfattningsrapport, detaljerad rapport eller rapport inför läkarbesök → välj period → Skapa rapport. PDF:en kan delas via e-post, AirDrop eller vilken annan app som helst.

Ger appen medicinska råd?

Nej. Dozify är enbart ett loggverktyg. Den rekommenderar inga doser och tolkar inga medicinska resultat. Rådgör alltid med din läkare eller ditt apotek inför kliniska beslut.
